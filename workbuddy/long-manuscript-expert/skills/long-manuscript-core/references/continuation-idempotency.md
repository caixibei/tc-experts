# 续接幂等与版本兼容

> 何时读我：跨会话续接项目、处理旧版本状态文件、重放同一操作、或需要判断“这次写入是不是重复了”时。
> 26.9.18 吸收自 `liuxue-yanxue-expert` 的 case-state 幂等日志与 `fbsir-internship` 的 task-snapshot 兼容字段。

## 1. 幂等三件套

任何会改变项目状态的操作必须带：

| 字段 | 作用 | 违反时的行为 |
| --- | --- | --- |
| `operationId` | 去重键 | 同一 ID 不同输入 → `operation_id_conflict`，直接失败 |
| `inputSha256` | 输入摘要 | 与既有记录不一致时拒绝，不静默覆盖 |
| `expectedRevision` | 乐观锁 | 与当前版本不符 → `revision_stale`，拒绝执行 |

**规则**：

- 同一 `operationId` + 同一 `inputSha256` → 返回既有结果，**不重复执行**。
- 同一 `operationId` + 不同 `inputSha256` → 冲突失败。**不得**用新输入覆盖旧记录。
- 丢响应时**先回读未决状态**，不生成新 ID 重试。生成新 ID 会制造重复条目。
- 并发写入用 `expectedRevision` 挡住；版本不匹配时把当前版本返回给用户，让用户决定是否基于新版重做。

## 2. 日志链完整性

事件日志每行记录 `previousSha256`，形成可校验的链。

- 校验失败 → `journal_chain_invalid`，**停止写入**并报告断链位置。
- 不得跳过校验继续追加，也不得“修复”链条（修补会掩盖真实断点）。
- 日志是**追加式**：不修改、不删除、不重排既有行。

## 3. 兼容字段

读取旧版本状态文件时：

| 机制 | 用法 |
| --- | --- |
| `legacyFields: {}` | 兜底存放本版本不认识但需要保留的旧字段。**读取时保留，写入时原样带回。** |
| `supersedes` | 显式替代链。新条目指向被替代的旧条目；**替代不删除旧条目**。 |
| `sourceRefs[].status` | `effective` / `withdrawn` / `unknown`。撤回的来源不删除，标 `withdrawn`。 |
| `assetState` | 模型产出固定标 `model_candidate`，不因反复出现而升级。 |

**纪律**：旧卡没有新字段时，**按本次需要补关联即可，不要求用户先补完整档案**。缺字段不是错误，强行编造才是。

## 4. 升级兼容声明

版本升级不得强迫用户学新操作：

- `preserveOrder: true` —— 旧入口顺序保留
- `requiredNewUserOperations: 0` —— 升级后不要求用户执行任何新操作
- `originalsReadOnly: true` —— 原件只读
- `preserveHumanEdits: true` —— 保留人工修改
- `preserveUnknownFields: true` —— 保留未知字段
- `autoMoveRenameDelete: false` —— 不自动移动、重命名或删除
- `rollbackDeletesNewUserAssets: false` —— **包回退不得删除用户新增的素材**

“继续”的语义是：**恢复当前可读材料中的目标、选择、已完成项、未决项和人工修改。不可读的历史保持未知，不说资料已丢失。**

## 5. 与续接胶囊的关系

- 胶囊是**用户可见文本**，不代表系统已保存状态；新会话只能依据用户再次提供的胶囊继续。
- 胶囊状态使用三态分栏（`用户已确认` / `模型暂定` / `未知`），**只有第一栏可以写“已确认”**。
- 章节数量、标题、当前停点必须**从本轮最终正文逐项重算**，不能复用草稿阶段的旧数字。
- 内部幂等字段（`operationId`、`revision`、`previousSha256`）**不进胶囊**，它们是工作状态而非用户需要的东西。

## 6. 检查清单

- [ ] 每次状态写入带 `operationId` + `inputSha256` + `expectedRevision`
- [ ] 重试复用同一 `operationId`
- [ ] 日志链校验通过，失败时停止而非继续
- [ ] 旧字段经 `legacyFields` 原样保留
- [ ] 替代关系用 `supersedes` 表达，旧条目未删除
- [ ] 胶囊中的数字来自本轮最终正文
- [ ] 未声称“系统已保存状态”

## 证据边界

本文件定义**幂等与兼容纪律**。幂等键、版本号与摘要只证明“这次操作没有重复”，**不证明内容正确、不证明宿主已持久化**。真实的文件状态仍以包外宿主的当前写入与回读回执为准。
