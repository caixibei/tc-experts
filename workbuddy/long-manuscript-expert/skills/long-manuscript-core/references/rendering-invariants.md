# 渲染不变量：格式可以变，语义不可以变

> 何时读我：把已成稿内容转换成另一种格式、导出交付、生成摘要或图表、或做任何“只改格式”的动作时。
> 26.9.18 吸收自 `industrial-park-investment-attraction-expert` 的 artifact-renderer 与 `fbsir-super-independent-board` 的 artifact-contract。

## 1. 单一语义写者

内容只有一个语义写者（`writing_owner`）。渲染层**只改格式**，不得修改事实、判断、排序、状态或语义。

**发现输入内部矛盾时停止并退回唯一语义写者，不自行修正。** 渲染器不是裁判，遇到“两处说法不一致”应该报冲突，而不是选一个看起来更顺的。

## 2. 双哈希门

渲染前后各记一次语义哈希：

```
semanticInputHash   渲染前的语义内容摘要
semanticOutputHash  渲染后的语义内容摘要
```

- 两者必须一致（转换只允许改变表现，不允许改变语义）。
- 宿主可计算时由宿主计算；包内不伪造哈希。
- 输入未过质量门或哈希不一致时，**退回相应写者**，不继续渲染。

## 3. 语义不可变字段

以下内容在任何格式转换中**必须保持原样**，包括强度、范围和限定语：

| 字段 | 不得发生的变化 |
| --- | --- |
| 结论与建议 | 不得加强、弱化或改写方向 |
| 证据状态 | `候选` / `未核实` / `已核实` 标签不得在转换中消失或升级 |
| 未知项 | **不得渲染成零、安全、无风险或“待补充”之外的任何确定性表述** |
| 最强反证 | **不得被放进不可见附录、折叠区、脚注或“其他考虑”** |
| 成立与失效条件 | 不得只保留成立条件而省略失效条件 |
| 人工复核边界 | 不得弱化为普通备注或“建议核实” |
| 用户决定 | **不得由 AI 建议推断**；用户未表态就写“未表态” |
| 限定语 | “约”“可能”“尚未”“在……范围内”不得删除 |

## 4. 允许的转换（白名单）

只有下列转换是允许的，且转换后必须保留原结论范围和证据强度：

| 从 | 到 |
| --- | --- |
| 长文 | 摘要（必须标注为摘要，不得当作全文） |
| 因果叙述 | 流程图 |
| 风险清单 | 风险矩阵或热力图 |
| 时间线叙述 | 时间轴 |
| 对比叙述 | 对照表 |
| 章节 | 演示页（含讲者备注） |

白名单之外的转换视为**内容改写**，走有界改稿流程，不走渲染流程。

## 5. 交付组合规则

- **一主一伴**：主交付格式一个，伴随格式最多一个。同时声称交付四五种格式通常是掩盖主格式没做出来。
- **降级不是达成**：格式降级链见 `../contracts/fallback-matrix.json`。降级产物必须明示为降级，并列出缺失的能力层。
- **改扩展名不是交付**：把 Markdown 存成 `.docx` 不构成 Word 交付。
- **未知不得渲染为安全**：风险未知时输出“未知”，不输出“低风险”。

## 6. 表格与 CSV 安全

导出 CSV 或表格时，对以 `=` `+` `-` `@` 开头的单元格内容做公式注入防护（前置单引号或加引号转义）。用户材料中的这类字符串可能是真实数据，也可能是注入载荷——**防护不改变数据本身，只阻止它被解释为公式**。

## 7. 三轴状态

渲染完成不等于交付完成。三轴状态与禁止组合见 `../contracts/delivery-state-machine.json`：

- `fulfillment`：内容做出来了没有
- `delivery`：用户拿到了没有
- `execution`：外部动作执行了没有

**`generated` 不是 `delivered`；`written` 不是 `readback_verified`；`connector_receipt` 不是 `delivery`。**

## 8. 导出前检查清单

- [ ] 语义不可变字段逐项比对，无强度漂移
- [ ] 未知项仍标未知，未变成“无”
- [ ] 反证与支持材料同等可见
- [ ] 人工复核边界未被弱化
- [ ] 用户决定与 AI 建议分开呈现
- [ ] 降级关系已明示
- [ ] 主格式与伴随格式合计不超过两个
- [ ] 导出产物已完成回读核验

## 证据边界

本文件定义**转换纪律**，不执行渲染、不生成二进制文件、不验证版式。渲染产物仍需按 `../contracts/delivery-state-machine.json` 的 `fullArtifactRequirements` 逐项取得证据。
