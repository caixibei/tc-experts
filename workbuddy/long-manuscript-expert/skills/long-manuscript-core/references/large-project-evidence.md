# 真实素材项目的交付闭环

本协议适用于资料整理、多模态观点提取、编年研究和长篇项目；单次截图故障记录的简化结构不推广为所有文稿的固定模板。

## 1. 先确定请求与授权

从最新用户原话提取目标、体裁、规模、材料范围，保留来源消息标记。用户明确给出的书名、五十万字、回忆录是已确认要求；“继续”只延续已提出的具体工作，不代表认可所有事实、目录和推断。不得遗漏后续用户更正，亦不得要求用户重复批准已经明确授权的普通处理步骤。

## 2. 盘点与优先级

统计从清单计算：文件数、目录数、字节数、命中数、重复路径、未遍历与截断分别记录。GB/MB必须统一单位后汇总；历史用户画像中的规模必须注明历史来源，不能称本轮全库分母。关键词命中只用于发现和排序，不能证明AI内容或排除未读视频。输出可直接打开的完整路径；不要把省略号路径或占位URL当作来源。

包内 `scripts/material-inventory.mjs` 提供只读元数据盘点，输出精确已观察文件/字节、命中、目录、符号链接跳过、错误和输出截断。限制超时/数量时报告partial；不打开文件正文、不跟随链接、不联网。它不是内容检索或语义去重器。用户不应看到工具内部字段，正文只呈现必要的范围与残余。

## 3. 多模态证据包

保留源视频引用、原始字节摘要（可取得时）、时长、抽帧命令、帧PTS映射、已读帧路径和去重图像计数；未验证PTS时标为估算位置。保留原始ASR文本与分段时间范围，修订另建对照表：原词→建议词→画面/音频/人工依据→待核状态。术语提示是识别输入，不是证据；只按ASR或模型视觉形成的文字不能称人工核实逐字稿。

音频和幻灯片来自同一视频，可以交叉对照，但不自动成为独立来源。长音视频分段处理并保留checkpoint、已完成范围和失败范围；不能将已有时长或片尾时间戳当成全部语音无遗漏。

确需本地依赖且用户已授权时，优先使用本项目专用环境及模型目录。发现共享缓存坏文件时，在项目目录重新下载并验证，不清理共享缓存或复用default环境后称“本次隔离”。包安装/模型下载与上传用户材料分别记账；大小正确不等于摘要、加载和推理校验均通过。宿主提供工具时可消费其当前回执，核心首值不得依赖固定ASR产品、外部服务或另装福帮手产品。

## 4. 分年研究与并行

每条主张分别保留：观点所属时间、文档发布/修订时间、目录归档年份、作者归属、原文锚点、来源验证状态。将新版课件回忆的旧事件放入旧年时，必须标“后期回述”；最高版本不是最早发表证据。未确定作者/年份的材料放入待定栏，不因一份写作计划日期推定全部章节同日完成。

联网条目区分搜索摘要、已打开页面与逐条支持。高声誉媒体不自动证明当前摘要或URL准确；先查链接完整性，再确认页面支持的是事件、身份还是具体观点。“本轮最早发现”不能写成“最早公开提出”。需对外使用的关键主张逐页核对；其余保留候选，不用“全都已核实”概括。

用户要求并行时，在宿主确有可用异步调度下先分发互不重叠的只读任务，再合流。实际调用起止不重叠时必须称“多代理顺序执行”。正文由单个写作负责人整合；子代理只返回有来源引用的证据包。每批冻结小范围输入、输出预算、超时、截止与失败回收；不把全会话原文和全部媒体传给每个子任务。

## 5. 最终交付清单

把完成过程收束为：冻结正文与辅助状态 → 完成最后编辑 → 每个要声明通过的文件全文回读 → 核对版本/内容一致 → 回复。最后回读之后不再修改该版本；确需修改就重开该文件的回读项。只回读变更处可报告“局部回读”，不能声称最终全文验收。

包内 `scripts/delivery-evidence.mjs` 提供纯函数，检查写入序列、最终摘要下的连续读取覆盖/EOF、计数与字节守恒、URL占位、来源身份和真实并发。调用方必须提供当前工具回执；检查通过仅为结构性证据，不是语义真实性或宿主强制拦截。仅在当前宿主已解析工具路径时调用；路径未知或读取受限时按同一清单人工式核验，并明确机器检查未执行。

篇幅预算由章节行求和，部数由不同部号计算。样章不能创造第一人称经历、动作或感官细节；没有素材的场景只能整段标为虚构示范或保留待补问题。五十万字目标不授权一次填充五十万字；先用有充分材料的一个章段验证笔调与事实密度，再扩展并保留每章预算及来源缺口。

宿主要求写memory时，只记必要项目状态，指向交付物；宿主自动注入的个人画像不得无关地进入正文。用户限定材料范围时遵守其范围。辅助状态的完成与读回必须单独记录，不能替代主稿交付。

## 6. 上下文与来源方法的吸收

每次从盘点进入研究、从研究进入写作时，重建当前证据包：用户原话及来源消息、当前目标、相关材料引用、未核事实、最近交付摘要和本轮待办。旧工具原文留在文件引用后，不重复塞入每次请求。不要假设能控制WorkBuddy自动压缩；只能维护本专家可见的项目材料。

`scripts/evidence-packet.mjs` 按字节预算选择来源引用，保留用户决策与未决项，超预算明确返回未装入的来源ID；无法容纳必要状态时失败，不静默丢失授权或未知项。其转写审查函数仅检查分段时间与校订依据，不进行ASR或宣称语音内容正确。

方法来源（2026-09-05核对）：

- [Anthropic上下文工程](https://www.anthropic.com/engineering/effective-context-engineering-for-ai-agents)：吸收按需引用、压缩后保留决策和未解决项、避免把所有边界例子堆入主提示。具体预算由本项目决定，不冒充厂商标准。
- [Anthropic多代理研究系统](https://www.anthropic.com/engineering/multi-agent-research-system)：吸收独立任务的同时分发、证据压缩回传和单点合流；其性能数据不作为WorkBuddy性能保证。
- [faster-whisper官方实现](https://github.com/SYSTRAN/faster-whisper)：支持词级时间戳和VAD；采用时间段与处理参数的记录方式，不将某个ASR模型设为必需依赖。
- [FFmpeg showinfo](https://ffmpeg.org/ffmpeg-filters.html#showinfo)：记录实际帧PTS；`fps`重采样后的时间不是原帧时间的充分证明，需同时保留输入PTS与输出映射。
- [W3C PROV-DM](https://www.w3.org/TR/prov-dm/)：区分实体、活动、责任主体及派生关系。原视频、帧、ASR、校订和综述各为独立对象，派生不改变其证据状态。
