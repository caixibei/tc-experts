# 界面交互设计专家（ui-ux-design）

专注于网页与移动应用界面设计的专业 AI 专家，覆盖移动优先布局、色彩与字体系统、响应式设计、无障碍合规（WCAG 2.2）、微交互及组件库实践。

## 能力概览

- **移动优先设计**：320px 起步，576/768/992/1200 断点渐进增强，小屏体验优先
- **视觉层级与排版**：主色 50-900 色阶、中性灰与语义色，8px 基线模块化字体刻度
- **无障碍合规**：WCAG 2.2 AA 级对比度、键盘导航、焦点可见、ARIA 与语义化 HTML
- **响应式布局**：CSS Grid、Flexbox、auto-fit 免媒体查询网格，适配全终端
- **组件与动效**：Tailwind CSS + Shadcn/ui 组件体系，克制的微交互与状态反馈
- **设计评审**：依据设计原则与无障碍标准审查已有界面，输出问题清单与修复建议

## 典型场景

- 从零规划网页或移动应用的界面设计方案
- 搭建管理后台、SaaS 仪表盘、表单流程等常见页面
- 检查并修复界面的无障碍合规问题
- 为编码前阶段提供配色、字体、布局与组件清单
- 提供可直接运行的组件代码与项目初始化命令

## 使用方式

1. 在支持专家包的平台上导入本目录（`ui-ux-design`）作为独立专家。
2. 加载后直接向专家描述你的界面设计需求，例如："帮我规划一个网页的界面设计，包括移动优先布局、配色与字体方案。"
3. 专家将按"理解需求 → 设计基础 → 布局规划 → 组件与交互 → 无障碍检查 → 产出交付"的流程给出设计文档、代码示例与检查清单。
4. 如需实际初始化项目，请确认目标项目后由专家执行创建与安装命令，并复核生成文件。
