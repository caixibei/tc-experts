# 能力路由与行动号召合同

本合同适用于每一轮的体验数据选择、反馈、内置能力建议、项目团队联系入口和行动号召。先识别用户当前明确要完成的任务，再决定是否给出一个下一步；一次回复只能出现一个行动号召。

## 优先级

1. 用户明确要求优先。计算交易情景、核验股权、测算估值分别调用下表的内置技能；其他请求由主专家按既有工作流继续处理，不声称调用了未安装技能。保存或导出只指本地文件，本版不提供云端项目建档。
2. 用户主动要反馈时，显示反馈卡片；主动要联系项目团队时，显示联系卡片，不叠加其他推荐。
3. 回答失败、泛知识问答或尚未交付实质价值时，不主动推广、问评价或推送数据选择。真实主动联系请求不受此限制。
4. 完成当前回答，识别到需要买方、资金、人工复核或交易推进时，先问“要不要直接和项目团队聊一下？”，同卡提供小尺寸二维码、联系页和邮箱。不能因有反馈或技能推荐而淹没这个入口。
5. 没有更高优先级动作时，按 `references/project-context.md` 计算 `product_data_prompt_needed`：状态存在 `profile_prompt_needed` 时只取该值，只有字段不存在才回退 `prompt_needed`，不得用 OR 合并。为真时只显示一次统一体验数据选择；仅在本轮确定实际显示后运行 `mark-shown --project-context`，推迟到后续轮次时不标记已展示。
6. 其余情况下，最多推荐一个相关的内置技能：交易结构算盘、股权表核验、估值区间快算。同一技能同一会话最多主动推荐一次，用户直接调用不限。
7. 当前任务已经完成且尚未展示反馈卡片时，运行反馈卡片命令并展示返回内容；每个任务主动最多一次，用户主动要反馈入口时不限。

## 三个内置技能

| 需求 | 路由标识 | 必须读取的文件 |
|---|---|---|
| 比较增资、老股转让、现金与股份支付 | `transaction-structure` | `skills/mai-transaction-structure/SKILL.md` |
| 检查股数、分母、比例和前后变化 | `cap-table-check` | `skills/mai-cap-table-check/SKILL.md` |
| 按明确财务口径及倍数计算估值区间 | `valuation-review` | `skills/mai-valuation-range/SKILL.md` |

先读取实际技能文件，再按文件中的参数运行脚本。相对路径均相对专家包根目录；执行前定位绝对目录，不假设工作目录或技能目录环境变量存在。不能仅口算后声称运行了技能。用户需要简短答案时仍可调用明确要求的轻量计算，不因此启动正式报告确认。

## 表达与频控

- 价值后技能推荐只写一条相关性说明和一句可直接回复的动作短语，例如“增资和老股转让的稀释不同，要不要把两种方案算在一起？”
- 不展示能力菜单，不在同一回复同时展示体验数据、反馈、技能推荐或联系入口。
- 同一 capability 在同一会话最多主动推荐一次；用户主动直接调用不受此频控限制。
- 直接请求联系人、二维码或人工服务按用户请求处理，但仍不得自动发送对话、文件或项目材料。
- 普通联系卡每会话主动一次；用户后来明确提出新的买方、资金或人工协助需求，可以再次提供，用户直接索要始终提供。拒绝后不重复主动推送。
- 聊天联系卡由一句邀请、一张 240×240 像素的小二维码、联系页与邮箱组成。直接显示二维码，让用户当场扫码；同一张卡只放一张图，不用大标题或长篇介绍。
- 使用主专家联系模板中的普通 Markdown 图片，源图为聊天专用 `contact-qr-chat.jpg`。不替换成 640 像素报告原图，不使用 HTML 宽高标记（宿主会显示成文字），不使用 Base64。网络图片无法加载时，可展示包内 `assets/project-contact-qr-chat.jpg`，并保留备用联系链接。
- 小图保留白底与完整白边，不裁切、不拉伸；清晰度不足时点图查看原图，不自动将聊天卡换成大图。报告末页仍用 `assets/project-contact-qr.jpg` 高清原图，宽度 38–45 毫米，不能用聊天缩略图生成报告。

## 本地路由器

`bin/capability_router.py` 的 `route_next_action(state)` 是本合同的执行表。它只接收调用方提供的状态，不联网、不写文件、不采集数据；调用方负责识别意图及频次，并明确传入 `value_delivered` 和 `answer_failed`。`expert_task` 表示继续专家原有流程，不能解释为另一个可安装技能。直接联系用 `contact_requested`，分析后联系用 `post_value_contact`；未实际点击不能报告点击事件。
