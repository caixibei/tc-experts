# 估值区间快算

**先把价格算到一个能谈的区间，再决定值不值得往下走。**

把用户确认的财务指标、估值倍数和企业价值调整项转成可复算的价值区间。一次使用会得到企业价值或股权价值、关键敏感性和下一步，并说明结果为什么成立、什么变化最影响价格。

本技能用于交易早期的价格方向判断，不搭建完整财务模型，不出具正式估值报告、公允价值、投资意见、税务或诉讼意见，也不承诺成交价格或投资结果。

## 何时调用

以下任务直接调用：

- 用户提供收入、息税折旧摊销前利润、净利润或净资产，希望按明确倍数测算估值区间；
- 用户需要把企业价值转换为股权价值；
- 用户希望判断现有报价位于初步估值区间的什么位置；
- 用户希望查看财务指标或倍数变化的敏感性。

以下任务转向其他能力：

- 完整折现现金流模型、五年预测、资本成本和终值模型，转入正式估值服务；
- 正式估值报告、董事会材料或融资材料，转入「MAI Lab并购Agent」；
- 二级市场目标股价或证券买卖建议，本技能不承接；
- 股本分母、股权比例和稀释核验，转入「股权表核验」；
- 支付、治理、业绩承诺和交割安排，转入「交易结构算盘」；

## 最低输入

给出数值区间前，需要确认：

1. 估值对象和估值目的；
2. 估值时点、币种和金额单位；
3. 财务指标、报告期和财务指标来源；
4. 倍数低端、高端和倍数来源；
5. 使用企业价值倍数且需要股权价值时，债务、现金和其他调整项。

来源可以是公开披露、用户提供资料或明确标注的用户假设。缺少财务指标或倍数依据时，只给方法建议和资料清单，不生成数值区间。不要要求用户重复提供当前会话中已经明确的内容。

## 方法选择

首版支持 `EV/Revenue`、`EV/EBITDA`、`P/E` 和 `P/B`，详细选择条件见 `references/方法与证据规则.md`。

先判断哪个财务指标最稳定、最能解释当前价值。净利润小于或等于零时不使用市盈率；息税折旧摊销前利润小于或等于零时不使用 EV/EBITDA；净资产小于或等于零时不使用市净率。

单一可比对象只能形成“单一参照的初步区间”。控制权溢价、少数股权折价、流动性折价和跨境折价必须有依据，不得自动套用固定比例。

## 本地计算

输入充分后调用：

```bash
python3 "${CLAUDE_PLUGIN_ROOT}/skills/mai-valuation-range/scripts/calculate_valuation_range.py" \
  --method ev_ebitda \
  --metric-base 1.2 \
  --multiple-low 6 \
  --multiple-high 8 \
  --currency 人民币 \
  --unit 亿元 \
  --valuation-date 2026-08-30 \
  --metric-period 2025年度 \
  --metric-source "用户提供，待核验" \
  --multiple-source "用户确认的可比区间"
```

用户明确给出财务指标低、中、高情景时，增加 `--metric-low` 和 `--metric-high`。需要企业价值桥接时，至少同时提供 `--gross-debt` 与 `--cash`；租赁负债、优先权益、少数股东权益和非经营性投资按实际情况单列。

本地候选计算不联网，不查询公共数据，不上传输入。脚本没有公共数据时不得自行补造倍数、财务指标或可比对象。

## 结果解释

用户输入含有英文通用估值词时，先翻译为中文再输出。不得单独使用英文通用词作为标题、表头或结果标签；标准估值缩写首次出现时与中文全称并列，后文优先使用中文简称。公司法定名称、证券代码或必须逐字引用的文件原文可保留，并在首次出现时补充中文说明。

按以下顺序回复：

1. **测算结论**：方法、估值时点、币种、金额单位和结论等级；
2. **价值区间**：企业价值或股权价值的低值、区间中点和高值；
3. **企业价值桥接**：适用时列出每项调整；
4. **敏感性**：只使用用户确认的财务情景和倍数区间；
5. **依据与假设**：报告期、来源和待核实事项；
6. **适用边界**：能否用于内部讨论及正式使用前的缺口；
7. **下一步与收尾**：最多两个后续动作；符合下方频控时才展示反馈入口。

区间中点只用于阅读，不代表独立观察到的市场价格。债务或现金未知时只给企业价值并标注“股权价值待补”。

不得展示私有判断库、客户材料、私人关系、联系人、生产凭据或其他项目资料。不得自动把完整对话、文件或财务数据传给其他技能。

## 异常与降级

- 方法与财务指标不兼容时停止计算，并建议切换方法；
- 倍数低端高于高端或财务情景顺序错误时停止计算；
- 财务期、估值时点或倍数时点不一致时标记“尚未核实”；
- 企业价值桥接项不完整时保留企业价值，不把未知项当作零；
- 用户要求正式对外定价、公允意见、融资发行、诉讼税务或完整折现现金流时，标记“需要正式估值”。

数据保存和反馈边界见 `references/数据与反馈说明.md`。
