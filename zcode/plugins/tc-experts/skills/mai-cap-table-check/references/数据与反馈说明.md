# 数据与反馈说明

## 本地候选

当前本地核验不联网、不上传、不持久保存项目内容，也不自动查询工商、交易所、股东名册或监管规则。

程序只读取本次调用明确指定的文件并输出结果：

- 不修改或覆盖用户原文件；
- 不把原始股权表写入日志；
- 不把股东名称、持股数量或交易金额发送到外部服务；
- 不与其他项目混用数据；
- 不在错误信息中回显原表内容。

## 未来公共服务

只有在用户可见的数据说明、访问控制、查询、导出和删除机制上线后，才接入腾讯云上海公共服务。

在法律允许且完成必要告知的范围内，可以记录以下产品事件：

- 账户或组织的去标识化标识；
- 技能标识和版本；
- 单表体检或交易前后对表；
- 文件类型；
- 表格数量和有效行数；
- 可以继续使用、修正后再使用或尚未完成核验；
- 问题类别、严重程度和数量；
- 使用时长和重试次数；
- 下一技能点击；
- 用户反馈选项；
- 用户自愿提交的文字建议。

上述产品事件默认保留180天，用于衡量完成率、误报、失败原因、产品转化和后续改进。反馈及用户自愿填写的信息保存365天；联系信息从最后一次联系意向起保存12个月。

普通产品事件不得包含：

- 原始股权表；
- 股东名称；
- 持股数量和持股比例；
- 交易金额；
- 联系方式；
- 用户粘贴的项目正文；
- 客户身份和项目名称。

## 经用户同意保存的项目内容

只有用户明确选择“保存到并购项目档案”或主动提交具体问题样本时，才保存相关项目内容。

经批准提交的项目内容默认保留180天。用户可以查询、导出或删除；删除请求覆盖主存储，并进入后续备份清理周期。为安全和合规保留的必要审计记录不得包含项目正文。

不得用默认勾选、模糊按钮或反馈操作代替用户对保存项目内容的明确同意。数据用途、范围或期限变化时，重新更新用户可见说明。

## 反馈

反馈展示与频控以 `SKILL.md` 的“体验数据与反馈”为准。

默认反馈记录：

- 技能标识和版本；
- 本次模式；
- 结果状态；
- 问题类别；
- 用户选择的反馈项；
- 不含项目正文的结果编号。

“还没解决”的可选原因用于识别口径缺口、解析失败、规则误报或缺少功能。

用户希望附带原始表格、股东名称、持股数量、交易金额、联系方式或其他项目内容时，必须另行说明用途和保存期限并取得明确同意。

## 用户权利

未来公共服务上线后，用户至少可以：

- 查看保存了哪些项目内容；
- 导出本人或本组织有权访问的内容；
- 删除经批准保存的项目内容；
- 撤回后续使用授权；
- 提交错误更正和产品反馈。

公共服务、权限和删除能力未完成验收前，不得对外宣称这些云端功能已经上线。
