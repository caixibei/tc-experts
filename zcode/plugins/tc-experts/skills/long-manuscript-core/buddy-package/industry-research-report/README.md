# 行业研究报告Buddy

> 状态：内部设计与评测候选。本目录不是 WorkBuddy 官方 Buddy 应用上传格式，尚未上传、预览、审核或发布。平台映射见 `open-platform-mapping.json` 与 `../../references/workbuddy-open-platform-boundary.md`。

## 目的

验证第三方依托福帮手长文档内核构建垂直应用的最小闭环：本地PDF、文本、表格和可选网页资料进入证据链，生成可编辑、可追溯、可审阅的行业研究报告。

## 输入角色

- Reference：决定报告结构、章节职责、引用风格和版式要求。
- Content：决定事实、数据、访谈和原始资料。
- 可选公开网页：只用于补充需要最新核验的事实，必须记录来源和时间锚。

同一文件同时作为Reference和Content时，必须分开记录使用范围，不得把参考范文中的事实静默当作当前项目事实。

## 输出

- 报告目录和章节任务；
- 可编辑报告正文；
- Claim—evidence回链；
- 时间锚缺口清单；
- 不确定性登记；
- 发布前人工复核卡；
- 本地新版本写回回执。

## 首值

未连接外部服务时，仍从用户当前选定的本地材料生成材料理解卡和报告首节。不得等待连接器，不得声称已经完成网页查证。

## 发布门

以下情况阻断对外发布：

- 关键主张没有来源锚点；
- 时间敏感事实没有当前来源或时间锚；
- 来源冲突未裁决；
- 关键数字只有低置信OCR；
- 版权、隐私或外发授权不清；
- 文件已写入但没有回读成功。
