## :open_file_folder: 仓库结构

```text
📁 tc-experts/
├── 🗂️ workbuddy/             ← 🤖 WorkBuddy 专家包（15 个）
│   ├── agents/               ← 🧙 专家定义（*.md）
│   ├── skills/               ← 🧩 专属技能
│   └── avatars/              ← 🖼️ 专家头像
└── 🧩 zcode/
    └── 📦 plugins/
        ├── marketplace.json  ← 🏪 插件市场清单
        └── tc-experts/       ← ⚙️ TC Experts 插件本体
```

> :bulb: 各专家包内含 `agents/`（专家定义）、`skills/`（专属技能）与 `avatars/`（头像）等，具体以各包实际内容为准。

- :file_folder: 插件内含目录：`assets` :framed_picture: · `bin` :gear: · `contracts` :receipt: · `licenses` :balance_scale: · `references` :books: · `rules` :scroll: · `skills` :jigsaw:

## :rocket: 快速上手

1. :eyes: 在上方「专家团一览」中找到目标专家；
2. :point_right: 点进对应目录，阅读该包的 `README.md` 了解能力详情；
3. :open_file_folder: 按需取用包内的 `agents/` 专家定义与 `skills/` 专属技能；
4. :gear: ZCode 用户可基于 [`zcode/plugins/marketplace.json`](./zcode/plugins/marketplace.json) 安装 `tc-experts` 插件。
